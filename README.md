### ecoPrimal

Sovereign distributed computing in Pure Rust. Building [ecoPrimals](https://github.com/ecoPrimals) —
15 composable daemons that replace AWS, OpenSSL, Kubernetes, and CUDA with
self-hosted infrastructure on commodity hardware.

**98,955 tests** · **3.6M lines of Rust** · **175+ papers reproduced** · **`#![forbid(unsafe_code)]`**

Every commit is AI-assisted — human constraint + AI implementation.
[K-NOME methodology](https://primals.eco/methodology/k-nome-programming/):
I decide *what* and *why*, the agent implements *how*.
